# CS300-Portfolio
Projects from CS300
Reflection
What was the problem you were solving in the projects for this course?
The primary challenge I addressed involved organizing course information for a Computer Science advising program. This required loading data from a file, storing course numbers, titles, and prerequisites, enabling course searches, and printing the data in order. In Project One, I evaluated a vector, hash table, and binary search tree to determine the most suitable data structure. In Project Two, I implemented the system using a binary search tree.
How did you approach the problem? Consider why data structures are important to understand.
I addressed the issue by dividing the program into smaller tasks and creating pseudocode to understand how each data structure would handle them.  I evaluated how a vector, hash table, and binary search tree would load, search, store, and print course information, also comparing their runtime and memory usage. This process helped me realize that the choice of data structure significantly impacts program efficiency. I ultimately chose a binary search tree for its organized storage by course number, efficient search capabilities, and the ability to print courses in order through an in-order traversal.
How did you overcome any roadblocks you encountered while going through the activities or project?
One challenge was understanding how different data structures perform similar tasks in different ways. Breaking the project into smaller parts made it easier, and I initially outlined logic in pseudocode before coding in C++. I tested components as I built them, which helped identify issues with file loading, inserting courses into the tree, searching, and displaying information. This step-by-step approach made debugging manageable.
How has your work on this project expanded your approach to designing software and developing programs?
This project reshaped my approach to software design by encouraging me to focus more on the program's structure before coding. In the past, I mainly aimed to get the program to produce correct outputs. Now, I recognize the importance of considering data storage methods, search and sort frequencies, and how data structure choices influence performance. Evaluating different solutions beforehand revealed that multiple approaches can solve the same problem, but some are more aligned with the requirements than others.
How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
This course taught me the importance of organizing my code intentionally. In Project Two, I used a Course structure to group related details and a BinarySearchTree class to separate tree operations. I split the program into functions for tasks like loading courses, inserting nodes, searching, and printing. Descriptive names, comments, and dedicated functions improve readability and flexibility, letting parts change without rewriting the whole program. Overall, I learned that good programming isn't just about functionality but also about creating understandable, maintainable, and easily upgradable code.
